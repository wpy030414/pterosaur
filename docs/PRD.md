# PRD — Pterosaur 网页音乐播放器

## 产品目标

- 让用户打开网页即可搜索、发现并畅听音乐，**无需注册或登录本应用**。
- 提供接近 Apple Music 的播放体验：流畅的发现流、沉浸的全屏播放页、逐行同步歌词、完整的播放控制。
- 为愿意登录网易云/B 站账号的用户解锁 VIP 曲目/高清码率与字幕歌词，会话仅存于其本机浏览器。
- 登录后自动开启资料库云同步，换设备无缝接续。

## 用户与使用场景

- 目标用户：想在浏览器里听歌、不愿装客户端、不想为「随便听听」注册账号的普通用户；以及拥有网易云 VIP、希望在自托管播放器里用自己会员权益的用户。
- 典型场景：
  - 打开首页，浏览推荐歌单，点一首就开始听。
  - 搜索「陈奕迅 我们」，在「歌曲」tab 点结果播放，或在「MV」tab 看 B 站 MV 的纯音频版（字幕作歌词）。
  - 切到全屏看歌词、拖进度、点歌词行跳转；移动端点封面进入专注歌词模式。
  - 把喜欢的歌加红心收藏，或新建本地歌单整理。
  - 登录网易云后播放 VIP 曲目，或登录 B 站后解锁高清码率与字幕歌词。
  - 用键盘快捷键（空格播放/暂停、←→ 快进快退、N/P 切歌）盲操作。
  - 换设备登录同一账号，资料库自动同步。

## 核心问题

- 浏览器不能直连网易云音频：真实音频地址是 `http://` 且接口无 CORS，直接在页面请求会被混合内容与跨域策略拦截。
- 免登录无法播放 VIP/付费曲目。
- 老项目只能靠手动输入歌曲 ID 添加，没有搜索与发现能力，体验远落后于主流音乐应用。

## 功能及其意义

| 功能                                      | 解决什么                       | 为什么需要                                           |
| ----------------------------------------- | ------------------------------ | ---------------------------------------------------- |
| 后端音频代理（同源 + https 改写 + Range） | 浏览器无法直连上游音频         | 这是「能出声」的前提，没有它前端拿不到可播放的音频流 |
| 网易云搜索（歌曲/艺人/专辑/歌单）         | 用户不知道歌曲 ID              | 让「想听什么就搜什么」成立，是最核心的入口           |
| B 站 MV 渠道（搜索 + 纯音频播放）         | 网易云缺的视频内容             | MV 的 DASH 音频轨作独立渠道，字幕作歌词              |
| 发现（推荐/精品歌单/排行榜）              | 不知道听什么时有内容可逛       | 对齐 Apple Music「立即收听/浏览」                    |
| 电台（随机播放）                          | 想要「不挑歌」的伴随式收听     | 低成本提供无限流体验                                 |
| 歌单 / 艺人 / 专辑详情                    | 点进合集要能看到并播放全部曲目 | 发现流的落地页，承接播放                             |
| 全屏播放页 + 逐行同步歌词                 | 播放时缺少沉浸视觉与歌词       | Apple Music 体验的标志性部分；移动端专注歌词模式     |
| 播放控制（播放/暂停/上下曲/进度/音量）    | 基础听歌操作                   | 播放器立身之本                                       |
| 播放队列                                  | 看不到、管不了待播列表         | 支持查看、跳播、移除、清空，掌控播放顺序             |
| 循环 / 随机模式                           | 听完一首后的续播策略           | shuffle 一次性洗牌后顺序游走，手动与自然推进一致     |
| 收藏（我喜欢的音乐）                      | 想留住喜欢的歌                 | 高频刚需，本地 IndexedDB 持久化，免登录也能用        |
| 最近播放                                  | 想回到刚听过的歌               | 免登录的轻量历史                                     |
| 本地歌单                                  | 想自己整理曲目集合             | 无需云端账号即可建单、加删曲目                       |
| 唱片盒（收藏艺人 + 专辑）                 | 管理非单曲收藏                 | 艺人/专辑双分区，进入冻结防误触                      |
| 云端资料库同步                            | 换设备后收藏/歌单丢失          | 登录后自动开启，SQLite + SSE 多设备近实时同步        |
| 自定义应用背景 + 自动取色                 | 默认红主题单调                 | 图片/视频作背景，自动派生产品主题色                  |
| 网易云登录（扫码）                        | VIP 曲目免登录播不了           | 解锁完整曲库；会话只存浏览器 cookie                  |
| B 站登录（扫码）                          | 未登录无字幕列表               | 解锁字幕歌词与更高音频码率                           |
| 明暗主题                                  | 不同环境下的观感偏好           | 跟随系统或手动切换，View Transitions 圆形揭示        |
| 键盘快捷键                                | 高频操作的效率                 | 无需鼠标即可控制播放                                 |
| 播放受限提示 + 弱网韧性                   | 故障时用户困惑/体验中断        | 明确原因 + 看门狗自动恢复                            |
| 曲目/歌单打包下载（翻录）                 | 想离线留存                     | 整集下载含封面，后台持续                             |
| 队列预载（前后各 2 首）                   | 切歌等网络                     | 网络良好时 SW 自取预热，封面/歌词同步预载            |
| PWA（可安装 + 媒体离线缓存）              | 离线不可用                     | 16GB LRU 媒体池，外壳 7 天过期                       |

## 功能之间的关系

- 「后端代理」是所有播放能力的地基：搜索、歌单、电台、B 站 MV 最终都通过它把曲目交给音频引擎播放。
- 「发现 / 搜索 / 电台」是三条并列的内容入口，搜索页另设「MV」tab 作为 B 站独立渠道。
- 「歌单 / 艺人 / 专辑」三级详情页承接发现与搜索的点击，最终汇入播放队列。
- 「收藏 / 最近播放 / 本地歌单 / 唱片盒」构成资料库，既能在首页快捷入口露出，也能作为播放源。
- 「网易云登录 / B 站登录」遵循单活动账号模型：最多登录一个第三方账号，登录后无其余登录入口。
- 「云同步」登录后自动开启，以 `source:accountId` 为锚点、云端权威，多设备近实时同步资料库。

## 范围与非目标

- 范围内：网页端的发现、搜索、播放、歌词、队列、资料库、唱片盒（收藏艺人+专辑）、网易云与 B 站登录解锁、自定义应用背景、云同步资料库；可安装的 PWA（应用外壳与已播放音频/封面的本机缓存，外壳 7 天过期）；歌单/专辑打包下载（附带封面 `cover.<ext>`）。
- 范围外：
  - 纯静态部署（必须有 Node 后端）。
  - 自建音源、音频转码、视频播放（B 站仅取音频轨）。
  - 多用户账号体系、社交/评论/分享。
  - 移动端原生 App、桌面客户端。
